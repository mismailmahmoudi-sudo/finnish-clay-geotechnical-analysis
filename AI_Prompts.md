
# AI Prompts Documentation

## 1. Purpose

This document describes the use of artificial intelligence during the development of the Finnish Clay Geotechnical Analysis project, conducted as part of Laboratory 3 — Open and Reproducible Science (ING8100) at Polytechnique Montréal.

The objective is to ensure transparency regarding the use of AI-assisted tools.

## 2. AI Tool Used

- **Tool:** ChatGPT
- **Provider:** OpenAI
- **Model:** GPT-6
- **Purpose:** Assistance with content drafting and project organization.

AI assistance was used to support the preparation and organization of project documentation, including:

- README.md
- CODE_OF_CONDUCT.md
- CONTRIBUTING.md
- AI_Prompts.md

All AI-assisted content is subject to review and verification by the project contributors.

## 3. Most Relevant Prompt

### 3.1 Context

The project focuses on the analysis of geotechnical properties of four Finnish clay deposits: Haarajoki, Suurpelto, Tolsa, and POKO.

The dataset is available through Borealis:

https://doi.org/10.80240/FK2/DZGAMU

The project requires the preparation of structured documentation and the organization of a reproducible research workflow using GitHub.

### 3.2 Prompt Used

"Give me the Markdown file content according to the requirements of this section"

### 3.3 Expected Output

A clear and structured README.md following the provided template and adapted to the project's dataset.

The document should include:

- General dataset information.
- Data availability and licensing.
- Data and file descriptions.
- Data collection and processing methodology.
- Research objectives.
- Reproducibility and project organization.

## 4. AI-Assisted Activities

ChatGPT was used to assist with:

- Drafting and structuring project documentation.
- Organizing the different stages of the laboratory.

The AI-assisted documentation was prepared using the laboratory instructions, the provided README template, and the Contributor Covenant 3.0 as reference materials.

All generated content is subject to review and verification by the project contributors.

## 5. Verification and Limitations

AI-generated content may contain errors or incomplete information.

Project contributors remain responsible for:

- Verifying the accuracy of information.
- Reviewing and adapting drafted content.
- Checking consistency with the laboratory instructions.
- Respecting academic integrity requirements.
- Ensuring that project documentation is accurate and reproducible.

AI assistance does not replace the scientific judgment and responsibility of the contributors.
